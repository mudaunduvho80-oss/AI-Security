# AI Security System

## 📌 About the Project

The **AI Security System** is a computer-vision security project designed to detect objects or people using a camera and provide an alert when a specified detection occurs.

The project combines **Python, OpenCV, and YOLO** to create a real-time monitoring system.

## 🚀 Features

* Real-time camera monitoring
* AI-based object detection
* Automatic detection of specified objects
* Security alert system
* Real-time detection results
* Configurable detection settings

## 🛠️ Technologies Used

* **Python**
* **OpenCV**
* **YOLO**
* **Computer Vision**
* **VS Code**

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/mudaunduvho80-oss/AI-Security.git
```

### 2. Open the project

Open the project folder in **VS Code**.

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the system

```bash
python main.py
```
